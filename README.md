## 概要

大学食堂を対象に、YOLO と DeepSORT を用いた人流カウントシステムを構築し、  
計算資源に制約のある実環境下での精度向上手法について検討しました。

特に以下について扱っています。

- 入退室人数カウント
- 線分ベースのカウントライン
- フレームスキップ環境での最適化
- DeepSORT パラメータ調整
